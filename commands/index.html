    Commands Overview

    Melo uses Discord’s native slash commands. Start typing / in any channel where Melo has access to see the autocomplete list.

    This page lists public commands only.

    Command map

    65 public commands
    9 categories
    5 access tiers
    1 slash-only interface
    Category Focus Typical access
    Channels Slowmode and temporary voice channels Moderators / admins
    Community Polls, giveaways, and reputation Mixed
    Config Setup, language, and configuration backups Owners / managers
    Economy Wallets, rewards, games, and transfers Mixed
    Fun Quick entertainment commands Public
    Logging Audit logging and event toggles Administrators
    Moderation Warnings, bans, timeouts, and automod Moderators / admins
    Roles Role inspection Public
    Utility Bot info, help, member tools, and diagnostics Mixed

    How to browse commands

    1. Open the relevant category page for a focused summary.
    2. Use /help in Discord for an interactive command browser.
    3. Check the permissions guide if a command does not appear for you.

    Missing a command?

    If a command is not listed here, try /help in Discord first. Some commands may be disabled in your server or limited by permissions.
