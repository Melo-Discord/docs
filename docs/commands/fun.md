# Fun

The Fun category is lightweight. These commands are good for quick reactions and casual chat activity.

## Commands

| Command | What it does |
|---|---|
| `/8ball` | Ask the magic 8-ball a question |
| `/advice` | Get a random piece of advice |
| `/cat` | Fetch a cat image |
| `/coinflip` | Flip a coin |
| `/dadjoke` | Show a dad joke |
| `/dog` | Fetch a dog image |
| `/fact` | Get a random fact |
| `/joke` | Show a joke |
| `/pokemon` | Fetch Pokémon-related content |
| `/rps` | Play rock-paper-scissors |
| `/urban` | Look up an Urban Dictionary definition |

## How to use the category well

- Use `/8ball` and `/coinflip` when you want a quick decision without adding noise.
- Use `/cat` and `/dog` when you want a reaction image instead of another text reply.
- Use `/rps` when you want a self-contained mini-game.
- Use `/urban` carefully if your community prefers lighter or filtered language.

!!! note "No setup required"
    Fun commands need little setup. If one is unavailable, the cause is usually permissions or a wider bot issue.
