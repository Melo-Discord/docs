## What Melo is

Melo is a Discord bot for moderation, community features, economy, logging, and server setup. It is slash-command only, so people can discover commands in Discord and only see commands they can use.

<div class="stat-row">
  <div class="stat-chip"><strong>65</strong> public commands</div>

## Fast path

1. Open [Getting Started](getting-started.md) and invite Melo through Discord’s OAuth2 flow.
2. Run the setup wizard with `/setup start`.
3. Use `/help` in Discord to browse every public command category.
4. Move straight to the [Command Reference](commands/index.md) if you already know what you need.
